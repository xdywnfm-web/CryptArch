# CryptArch V2 Beta (WPF)

The Windows interface uses C# / WPF. The standalone Python worker is in `engine`. The public installer downloads and verifies FFmpeg during setup; no Python installation is required.

Queue shows the files from the current or last batch. To set the output folder, compression parameters or interface language, open Settings.

See the [English build instructions](../README.md) or [инструкцию на русском](../README.ru.md).
